# 浙旅智创前端

Vue 3 + TypeScript + Vite 城市短视频工作台。当前已对接 `zlzc` Spring Boot 后端的登录、用户信息与项目管理接口。

## 本地启动

1. 按后端仓库说明准备 MySQL、Redis，导入 `sql` 脚本并启动 `zlzc-admin`（默认 `http://127.0.0.1:8080`）。
2. 安装并启动前端：

```bash
pnpm install
pnpm dev
```

开发服务器会把 `/api` 代理到 `127.0.0.1:8080`。部署时可复制 `.env.example`，通过 `VITE_API_BASE_URL` 指向实际 API 前缀。

初始化管理员账号：`admin / admin123`。若后台启用了验证码，仍需输入登录页展示的图形验证码。

## 已接入能力

- 图形验证码、账号密码登录、JWT 保存与过期处理
- 当前用户、角色、组织信息
- 项目列表、筛选、创建、软删除
- 浙江省 11 市创建入口（城市暂存于项目描述，原因见 `BACKEND_GAPS.md`）
- 生成任务列表、状态筛选、关键词搜索、分页与详情弹窗
- 生成阶段时间线、失败原因、取消与重新生成交互
- 后端离线或接口报错时的加载、重试与错误状态

生成任务页面位于 `/tasks`。当前任务数据、取消和重新生成操作为前端演示实现，刷新页面后会恢复预置数据。

专业工作台、生成任务、审核、导出和知识资产页面保留产品交互演示，并在导航中标记为“演示”或“演示数据”；对应后端接口开放后再切换为真实数据。

## 生产构建

```bash
pnpm build
```

构建命令会先执行 `vue-tsc -b` 类型检查，再由 Vite 生成 `dist` 目录。
